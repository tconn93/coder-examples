# Project Plan: Advanced Task Manager

## Project Overview
Build a beautiful, productive task management web application with projects, labels, and priorities.

## Tech Stack
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express
- Database: PostgreSQL with Prisma
- Drag & Drop: react-beautiful-dnd or @dnd-kit

## Core Features
1. Projects / Workspaces
2. Tasks with title, description, due date, priority, labels, subtasks
3. Kanban board view + List view + Calendar view
4. Drag and drop between columns and tasks
5. Natural language date parsing (e.g., "tomorrow", "next Friday")
6. Search and filters
7. Dark mode

## Views
- Inbox
- Today
- Upcoming
- Projects
- Kanban
- Calendar

## Non-functional
- Real-time updates (optional with Socket.io)
- Keyboard shortcuts support
- Fully responsive

## Deliverables
- Complete full-stack application
- Good UX with smooth animations
