# Project Plan: Workout Tracker

## Project Overview
A mobile-first web app to log workouts and track progress.

## Tech Stack
- Frontend: React + TypeScript + Tailwind (PWA support)
- Backend: Node.js + Express
- Database: SQLite or Supabase

## Core Features
1. Exercise library (pre-populated common exercises)
2. Log workout sessions (sets, reps, weight)
3. Create custom workout routines
4. Progress charts (strength over time per exercise)
5. Calendar heatmap of workout activity
6. Personal records (PR) tracking
7. Rest timer

## UI/UX
- Clean, motivating design
- Dark mode by default
- Fully responsive (feels like a mobile app)

## Deliverables
- Complete workout logging and tracking system
