# Project Plan: Real-time Chat App

## Project Overview
Build a modern real-time messaging application similar to WhatsApp web or Slack.

## Tech Stack
- Frontend: React + TypeScript + Tailwind
- Backend: Node.js + Express + Socket.io
- Database: MongoDB or PostgreSQL
- Authentication: JWT or Clerk

## Core Features
1. User authentication (register/login)
2. Create/join chat rooms or direct messages
3. Real-time messaging with typing indicators
4. Online/offline status
5. Message reactions
6. Message editing and deletion
7. Dark mode

## Bonus Features
- File/image sharing
- Voice messages (optional)
- Read receipts

## Deliverables
- Fully working real-time chat
- Clean modern UI
- Mobile-responsive design
