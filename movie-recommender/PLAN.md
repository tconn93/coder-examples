# Project Plan: CineMatch - Movie Recommendation App

## Project Overview
A beautiful movie and TV discovery platform with personalized recommendations.

## Tech Stack
- Frontend: Next.js + TypeScript + Tailwind
- Backend: Next.js API routes
- External APIs: TMDB (The Movie Database)
- State: Zustand

## Core Features
1. Browse trending, popular, top-rated movies & TV shows
2. Detailed movie/TV pages with cast, trailers, similar titles
3. Search with filters (genre, year, rating)
4. "For You" personalized recommendations (simple algorithm based on liked genres/ratings)
5. Watchlist / Favorites
6. User ratings and reviews
7. Dark theme (cinema feel)

## Bonus
- Infinite scroll
- Trailer playback modal

## Deliverables
- Polished, responsive movie discovery app with real data from TMDB
