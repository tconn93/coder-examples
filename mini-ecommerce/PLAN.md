# Project Plan: Mini E-commerce Platform

## Project Overview
Build a clean, fully functional e-commerce frontend + backend.

## Tech Stack
- Frontend: Next.js 15 + TypeScript + Tailwind
- Backend: Next.js API routes or separate NestJS
- Database: Prisma + PostgreSQL
- Payments: Stripe (test mode)

## Core Features
1. Product catalog with categories and filters
2. Product detail page with images and variants
3. Shopping cart (add, remove, quantity)
4. Checkout flow
5. Fake payment integration with Stripe
6. Order history
7. Admin panel to add/edit products (simple)

## Design
- Modern, minimalist design (inspired by Apple or Shopify stores)
- Responsive on all devices

## Deliverables
- Complete working store with checkout
