# Project Plan: Minimal Blog CMS

## Project Overview
A full-featured blogging platform with admin panel.

## Tech Stack
- Frontend: Next.js 15 + TypeScript
- CMS/Admin: Custom dashboard or use Payload CMS / Strapi (optional)
- Database: PostgreSQL + Prisma
- Markdown support: MDX or remark

## Core Features
1. Public blog with clean reading experience
2. Admin dashboard to create/edit/delete posts
3. Categories and tags
4. Rich text editor (TipTap or React Quill)
5. SEO-friendly (dynamic meta tags)
6. Reading time estimation
7. Comment system (simple, no external service)
8. Dark mode

## Deliverables
- Beautiful blog frontend + functional admin backend
