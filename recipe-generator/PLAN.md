# Project Plan: AI Recipe Generator

## Project Overview
A web app where users input available ingredients and get AI-generated recipes.

## Tech Stack
- Frontend: Next.js 15 (App Router) + TypeScript + Tailwind
- AI Integration: OpenAI GPT-4o or Grok API
- Backend: Next.js API routes
- Database: Supabase or SQLite
- Authentication: NextAuth.js (optional)

## Core Features
1. Ingredient input (multi-select chips or text input with suggestions)
2. Filters: cuisine type, dietary restrictions (vegan, keto, gluten-free, etc.), cooking time, skill level
3. Generate recipe button → shows title, ingredients, instructions, prep/cook time, servings
4. Save favorite recipes
5. Recipe library with search
6. "Surprise me" random recipe mode

## UI/UX Requirements
- Beautiful food photography placeholders
- Step-by-step cooking instructions with checkboxes
- Responsive design

## Deliverables
- Fully functional Next.js web app
- Clear prompts engineering for consistent recipe output
- README with API key setup instructions
